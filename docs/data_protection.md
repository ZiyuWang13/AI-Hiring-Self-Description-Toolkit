# Data protection

This public repository is intentionally data-free except for synthetic fixtures.

## Never commit

- candidate names, contact details, résumés, or self-description text;
- raw recruitment-platform records;
- job descriptions, company names, or platform URLs;
- original job-level identifiers from the empirical studies;
- populated model prompts, requests, responses, or execution logs;
- frozen Stage 2 job pools;
- unpublished estimates, Golden References, or internal asset registries;
- API keys, tokens, local configuration, or private absolute paths.

## Safe contributions

- reusable source code;
- synthetic fixtures with visibly artificial identifiers;
- unit tests and deterministic synthetic demonstrations;
- methodological documentation that does not reveal restricted content; and
- reviewed public aggregate results, if separately approved in the future.

`.gitignore` reduces accidental staging but is not an access-control mechanism.
Every proposed commit must still be reviewed.
